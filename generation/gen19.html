How Generations Affect the Type Database

A Pokémon's generation does not determine whether it is strong or weak by itself. Instead, each generation adds new Pokémon, moves and evolution families that expand the options available for particular types.

This is particularly useful when building a type database because a single type may contain Pokémon from many different generations. For example, a Ground-type collection can include early-generation Pokémon alongside later additions with completely different stats, moves and battle roles.
