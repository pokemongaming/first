Burmy Overview

``` Burmy is a Bug-type Pokémon introduced in Generation 4. Unlike many Pokémon that only differ visually between forms, Burmy's cloak is important because its form can influence which Pokémon it evolves into. ```

Burmy Evolution

``` Burmy has different evolutionary outcomes depending on gender and cloak form. ```

👑
Female Burmy Evolves into Wormadam. The cloak form influences the resulting Wormadam form.
🦋
Male Burmy Evolves into Mothim regardless of Burmy cloak.
🧬
Cloak Matters Female Burmy evolution retains cloak-related form differences through Wormadam.
Evolution planning:

``` Check both Burmy's gender and cloak before evolving. A player collecting every Burmy evolution form may need multiple Burmy rather than simply evolving the first one they catch. ```

Shadow Burmy

``` Shadow Burmy is the Shadow variant of Burmy. Shadow Pokémon should be considered separately from regular Pokémon because the Shadow mechanic changes their battle profile and introduces additional investment considerations. ```

🌑 Shadow Burmy

``` Shadow Burmy remains the same Burmy species and retains its cloak form and Bug typing. The Shadow status is a separate gameplay state rather than an evolution. ```

Shadow Burmy Considerations

  • Shadow status does not change Burmy's basic species.
  • Shadow status should be considered before purification.
  • Resource costs can differ from regular Pokémon.
  • Availability depends on Team GO Rocket rotations.
  • Do not assume every Burmy cloak is always available as Shadow.
Availability warning:

``` Shadow Pokémon availability changes with Team GO Rocket lineups and events. Display current availability dynamically instead of permanently claiming that Shadow Burmy is obtainable. ```

✨ Purified Burmy

``` Purified Burmy is created when an eligible Shadow Burmy is purified. Purification should be considered carefully because it changes the Pokémon from its Shadow state into a Purified state. ```

💠 Purified Burmy

``` Purified Burmy remains a Burmy and retains its cloak. The main change is the removal of the Shadow status and the application of Purified Pokémon mechanics. ```

Species

Burmy remains Burmy after purification.

Cloak

The collectible form should remain relevant.

Shadow Status

Removed through purification.

Should You Purify Burmy?

``` The decision is mainly collection-dependent. Consider whether you want to keep a Shadow version for your collection before permanently removing its Shadow status. ```
